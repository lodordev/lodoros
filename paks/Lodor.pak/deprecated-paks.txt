# pak lingers forever: the GBA->mGBA migration left a duplicate Emus/*/MGBA.pak on every card
# already flashed, invisible to every OTA update.
#

# NEW version declares what it dropped). One card-relative path per line; '#' comments; globs (*)
# allowed and expanded against the card. Each removed pak's bytes are mirrored into the rollback
# set first, so "Revert last update" restores it. A path matching nothing is a silent no-op.
