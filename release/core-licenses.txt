LodorOS — Bundled emulator core licenses
=========================================

LodorOS bundles compiled libretro emulator cores. LodorOS does not modify these
cores; they are redistributed as built by their upstream projects and the
libretro community. Each core remains under its own license, listed below.

For every GPL-licensed core, the complete corresponding source code is publicly
available from the upstream repository linked next to it. If you cannot obtain
source from the link, open an issue on the LodorOS repository and we will
provide it.
