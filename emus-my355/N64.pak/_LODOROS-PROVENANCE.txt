2026-07-06 FIELD FIX (launch.real.sh + m64-watch.sh) — first on-hardware round exposed
that a standalone emulator sits outside minui/minarch's input loop, which is where this
firmware implements lid/sleep and the MENU contract:
  - MENU key = KEY_ESC on event0; stock CoreEvents bound Escape=Stop, so MENU instantly
    quit the game (reported as a "crash"; N64.txt showed a clean stop, rc=0).
    launch.real.sh now forces --set "CoreEvents[Kbd Mapping Stop]=0" / "Pause]=27" on
    every launch: MENU tap = pause toggle, and stale seeded configs are overridden too.
  - m64-watch.sh sidecar restores the lid contract: close = SIGSTOP + backlight off,
    reopen = resume; lid closed 120s or MENU held 2s = clean SIGTERM so the wrapper's
    save-push trap fires. FIFO-based evtest reader; trap-safe cleanup (never leaves a
    dark screen, a frozen emulator, or an orphaned evtest).
Off-device verification 2026-07-06: 15/15 in the simulated lid/input rig on Panther;
--set overrides proven applied by the real arm64 binary under qemu-aarch64.
